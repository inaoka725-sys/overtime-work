## 実装済み機能

### 残業報告書タブ
- [x] 作業入力フォーム（日付・氏名・社員番号・オーダー・件名）
- [x] 勤務区分（常用 / 休出 / 有給 / 代休）
- [x] 区分（現場作業 / 社内作業）
- [x] 作業時間（30分刻みセレクト、日またぎ対応）
- [x] 帰社後作業（現場→帰社継続。常用は本作業の残業起点を適用、休出は帰社後自身の開始時刻が起点）
- [x] 残業時間リアルタイム自動計算（普通残業H・深夜残業H）
- [x] 深夜作業手当自動判定（18:00〜翌6:00の常用勤務5h以上で3,000円）
- [x] 複数エントリー管理（登録・**編集**・削除・日付ソート）
- [x] 重複登録の防止（同一氏名・日付・開始時刻）
- [x] 帰社後開始 < 作業終了 のバリデーション
- [x] 合計サマリー表示（全登録分の普通残業・深夜残業・深夜作業手当）
- [x] **出力対象（年月＋旬）の選択UIと、対象件数・合計の表示**
- [x] 残業報告書 Excel 出力（**氏名×旬でシート分割** ＋ 一覧シート）
- [x] 残業報告書 CSV 出力（BOM付きUTF-8）
- [x] LocalStorage によるデータ永続化

### 旅費入力フィールド（旬報連携）
- [x] 日当（オーダーマスターから自動補完、金額は自由入力）
- [x] 交通費（交通機関・区間・金額・片道/往復選択）
- [x] 宿泊費（入力は可能。会社が予約・精算するため旬報Excelの出力対象外）
- [x] 備考

### 旬報タブ
- [x] 年月・旬（全期間 / 一旬 / 二旬 / 三旬）フィルター
- [x] 旅費明細一覧表示（画面の小計は入力確認用で宿泊費を含む）
- [x] オーダー別集計（日数・交通費・日当・勤務原価）
- [x] 旬報 Excel 出力（**会社原本の書式・12列・氏名×旬でシート分割**）
  - オーダー別集計（部=7 / 品名=旅費交通費 / 借方=540525 は原本の固定値）
  - 注記①②③・社名フッター・労務原価（日数×単価）

### 設定タブ
- [x] 氏名・社員番号・所属の登録
- [x] **勤務原価単価は管理者モード（`?admin=1` ＋ PIN）でのみ表示・入力**
- [x] LocalStorage による設定永続化
- [x] 入力フォームへの自動反映（氏名・社員番号）
- [x] オーダーマスター（件名・担当者・日当の自動補完、手動追加・削除、件数表示）
- [x] オーダー台帳の Excel インポート（「台帳」シート自動検出・列名自動マッピング）
- [x] オーダー台帳の自動反映（File System Access API ＋ IndexedDB、Chrome/Edge限定）
- [x] データのバックアップ／復元（JSON。オーダーマスターと勤務原価単価は含めない）
- [x] 全データ削除機能

### Excel出力基盤
- [x] ライブラリ2枚差し（読込: SheetJS最新版 `window.XLSX_READ` / 書出: xlsx-js-style `window.XLSX`）
- [x] 印刷設定の後注入（A4横・fitToPage・水平中央寄せ）
- [x] 罫線・塗り・和文フォント（ＭＳ Ｐゴシック）の適用
- [x] 生成失敗時にアラートで通知して中止（ボタン無反応にしない）

## アーキテクチャ

```yaml
構成: 単一HTMLファイル（サーバーレス）
ファイル:
  - index.html      # メインアプリ（HTML + CSS + JS 一体）
  - manual.html     # 操作マニュアル
  - overtime/docs/requirements.md     # 要件定義書
  - overtime/docs/SCOPE_PROGRESS.md   # 本ファイル
外部ライブラリ（CDN。社内サーバー移行時は同梱が必要）:
  - SheetJS xlsx-latest      — 読込用（window.XLSX_READ）
  - xlsx-js-style 1.2.0      — 書出用（window.XLSX、スタイル対応・SRI付き）
データ保存:
  - LocalStorage  — 作業データ / 設定 / オーダーマスター / 台帳メタ情報
  - IndexedDB     — オーダー台帳のファイルハンドル
  - sessionStorage — 管理者モードの解錠フラグ
ホスティング: GitHub Pages（main ブランチ / ルート）※社内サーバーへ移行予定
リポジトリ: https://github.com/inaoka725-sys/overtime-work
```

## 運用前提（2026/07/28 時点で確定）

- 従業員は1人1台・個人Windowsアカウント → LocalStorage のデータ混在リスクなし
- 労務原価は経理・管理部門が旬報上で記入する運用 → 従業員端末に単価を置かない
- 宿泊費は会社が予約・精算する → 従業員入力は不要（旬報Excelの出力対象外）
- オーダー台帳は Windows Server 上にある。社内PCはインターネット接続可
- 元請けからクラウド禁止 → 社内サーバーへの移行を計画中
