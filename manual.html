1回入力するだけで、残業報告書と旬報の両方を出力できます。

オーダー台帳を取り込む

オーダー番号を取り込んでおくと、入力フォームでオーダー番号を入れるだけで件名と日当が自動で入ります。設定タブの「オーダーマスター」欄で行います。

おすすめ：共有フォルダの台帳と自動連携する 「共有フォルダの台帳と連携する」を押して、共有フォルダにあるオーダー台帳のファイルを1回だけ選んでください。以降は、台帳が更新されるたびアプリが自動で最新の内容にします。毎回取り込み直す必要はありません。
連携できていると、緑色で「✓ ファイル名 / ○○件（台帳更新: 日時）」と表示されます。
・すぐに最新にしたいとき → 「今すぐ更新」
・「台帳へのアクセス許可が必要です」と出たとき → 「台帳に再接続」を押してファイルを選び直す
・連携をやめたいとき → 「連携解除」（取り込み済みのオーダーは残ります）
自動連携が使えるブラウザ この自動連携は Chrome / Edge でのみ使えます。それ以外のブラウザでは「このブラウザは台帳の自動連携に非対応です」と表示されるので、下の「ファイルを選んで手動で取り込む」から台帳（.xls / .xlsx）を選んで取り込んでください。台帳が更新されたら、そのつど取り込み直しが必要です。
1件だけ足したいとき 「手動追加」欄にオーダー番号・件名・担当者・日当を入れて「追加」を押すと、その1件だけ登録できます。台帳のファイルは書き換わりません。
9
データの取り扱いとバックアップ

入力したデータはどこにあるの？

データは自分のパソコンの中だけに保存されます 入力した内容は、使っているパソコンのブラウザの中に保存されます。会社のサーバーやインターネット上には送られません。そのため、ほかの人があなたのデータを見ることはできませんし、ほかの人の入力であなたのデータが上書きされることもありません。提出は、出力したExcelを渡すことで行います。
1台のパソコンを複数人で使うときだけ注意 同じパソコンを、同じWindowsのログイン（同じユーザー）で複数人が使うと、全員の入力が同じ一覧に混ざってしまいます。この場合は、入力するときに「報告者氏名」を必ず自分の名前にしてください。氏名ごとにシートが分かれて出力されます。
Windowsのログインが人ごとに分かれていれば、データも分かれるので混ざりません。
データが消えることがあります 次の場合、入力したデータは消えてしまい、元に戻せません。
・パソコンが故障した／初期化した
・パソコンを入れ替えた（新しいパソコンには引き継がれません）
・ブラウザの「閲覧履歴の削除」でサイトデータを消した
旬の途中でも、ときどきバックアップを取ってください。

バックアップと復元のしかた

設定タブの一番下「データ管理」欄で行います。

1

「データをバックアップ」を押す

登録した作業データと設定（氏名・社員番号・所属）が1つのファイルに保存されます。共有フォルダやUSBなど、パソコンとは別の場所に置いておくと安心です。

データをバックアップ
旬報バックアップ_山田太郎_20260728.json
2

戻したいときは「バックアップから復元」

保存しておいたファイルを選ぶと、その時点の状態に戻せます。新しいパソコンに移るときも、この操作でデータを引き継げます。

バックアップから復元
復元は「置き換え」です 今あるデータはバックアップの内容ですべて置き換わります（足し算ではありません）。実行前に確認メッセージが出るので、件数を見てから「OK」を押してください。
オーダーマスターはバックアップに含まれません オーダーの一覧は台帳から取り込み直せるため、バックアップには入っていません。復元後にオーダーの自動補完が効かないときは、設定タブで台帳を取り込み直してください。
「全データを削除」は最後の手段です 設定タブの赤いボタンを押すと、登録した作業データがすべて消え、元に戻せません。押す前に必ずバックアップを取ってください。

よくある質問
登録したデータはブラウザを閉じると消えますか？
消えません。入力した内容はパソコンの中に保存され、次にアプリを開いたときもそのまま残っています。ただし、パソコンの故障・入替え・ブラウザの履歴削除では消えてしまうので、設定タブの「データをバックアップ」をときどきご利用ください。
入力した内容は、ほかの人から見えますか？
見えません。データは自分のパソコンの中だけに保存され、会社のサーバーやインターネットには送られません。ほかの人の入力で上書きされることもありません。ただし、同じパソコンを同じWindowsログインで複数人が使う場合は、全員の入力が同じ一覧に混ざります。
パソコンを入れ替えます。データはどうすれば？
古いパソコンの設定タブで「データをバックアップ」を押してファイルを保存し、新しいパソコンの設定タブで「バックアップから復元」でそのファイルを選んでください。オーダー台帳は復元に含まれないので、新しいパソコンで取り込み直してください。
登録した内容をあとから直せますか？
直せます。「登録済み作業一覧」の「編集」を押すと内容が入力フォームに戻ります。直してから「更新する」を押してください。新しい行は増えず、元の行が書き換わります。
「同じ氏名・日付・開始時刻の登録が既に存在します」と出て登録できません
同じ内容を二重に登録しないための注意表示です。すでに登録済みでないか一覧を確認してください。同じ日に別のオーダーで2件登録したい場合は、開始時間を実際の時間に分けて入力するか、「帰社後にも作業あり」をご利用ください。
残業報告書のExcelが出せません／中身が空です
「出力対象」の年月と旬が合っているか確認してください。すぐ下に「出力対象（一旬）: ○件」と表示されます。0件のときはその期間に登録がありません。
宿泊費や備考が旬報のExcelに出ていません
会社の旬報の書式が12列で決まっているためです。入力した内容は旬報タブの画面に表示されるので、そちらで確認できます。ダウンロード前にも確認メッセージが出ます。宿泊費などの精算方法は事務にご確認ください。
オーダー番号を入れても件名や日当が出てきません
オーダー台帳がまだ取り込まれていないか、番号が台帳に無い可能性があります。設定タブの「オーダーマスター」で台帳を取り込むか、「手動追加」でその1件を登録してください。
オーダー台帳が更新されたら、取り込み直しが必要ですか？
Chrome / Edge で「共有フォルダの台帳と連携する」を済ませていれば不要です。自動で最新になります。それ以外のブラウザでは、台帳が更新されるたびに「ファイルを選んで手動で取り込む」から取り込み直してください。
「CSV」のボタンは何に使うのですか？
残業報告書と同じ内容を、表計算ソフトや他のシステムに取り込みやすい形式で保存するためのものです。通常の提出には「残業報告書 Excel」をお使いください。
残業報告書の右上にある4つの枠は何ですか？
「確認欄」の押印枠です。最大4名まで押印できます。空欄のまま印刷してご提出ください。
有給・代休の日も旬報に記録できますか？
できます。勤務区分で「有給」または「代休」を選んで登録してください。残業計算は行われませんが、日付・オーダー・日当などは旬報に記録されます。
旅費を入力しなくても使えますか？
はい、使えます。旅費欄は任意項目です。残業報告書だけが必要な場合は旅費欄は空欄のままにしてください。
交通費を往復で入力したら2倍になりますか？
はい。「往復」を選ぶと入力した金額が自動で2倍になって登録されます（例：210円 → 420円）。
日をまたいで作業した場合はどう入力すればいいですか？
開始を「22:00」、終了を「02:00」のように入力してください。終了が開始より前の時間の場合、自動で翌日として計算します。
休憩時間は自分で差し引く必要がありますか？
いいえ、不要です。開始・終了時間を入力すれば、規程に定められた休憩時間はアプリが自動で除いて計算します。
深夜作業手当（一律3,000円）は計算されますか？
はい、自動で計算されます。常用の日で、通常勤務の時間（勤務開始から9時間30分の間）のうち18:00〜翌6:00にかかる時間が5時間以上ある場合に「深夜作業手当 3,000円」が表示されます。休出の日には付きません。
計算結果が0.5時間単位になるのはなぜですか？
時間外手当基準の規定に基づき、0.5時間（30分）単位に四捨五入して表示しています。
複数の人のデータをまとめて管理できますか？
できます。報告者氏名を分けて登録すれば、Excelダウンロード時に氏名ごと・旬ごとに別シートで出力されます。
提出はいつまでにすればよいですか？
各旬の締め日から3営業日以内に、直近上司 → 所属部長 → 事務の順で提出してください。
